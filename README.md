# Strato Weather

A weather web application that displays current weather conditions and a 5-day forecast for a searched location.

## Features

- Search weather by city/location
- Current temperature and conditions
- Feels-like temperature
- Humidity
- Wind speed
- Current date and time
- Celsius / Fahrenheit toggle
- 5-day weather forecast
- Responsive weather-focused interface


Weather data is provided by Visual Crossing Weather.
